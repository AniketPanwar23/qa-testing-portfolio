# ITSM Software QA & Testing Portfolio — Aniket Panwar

Quality Assurance portfolio showcasing end-to-end manual testing, test case design, defect reporting, and competitive product benchmarking across core IT Service Management (ITSM) modules.

> **Note:** All test datasets, user records, and transactions contained in this repository are synthetic test data created specifically for QA validation.

## Modules Tested
* **Asset Management:** Hardware/software lifecycle tracking, allocation, and status transitions.
* **Change Management:** Change request workflows, approvals, and risk validation.
* **CMDB & Discovery:** Configuration item (CI) relationships, dependency mapping, and discovery rules.
* **Financial Management:** Cost tracking, budgeting, and financial record validation.
* **Incident Management:** Ticket creation, SLA tracking, escalation, and resolution flows.
* **Knowledge Base & Self-Service Portal:** End-user portal workflows, article publishing, and access permissions.
* **User Management:** Role-based access control (RBAC) and user provisioning.

## Folder Structure
* **`01_Project_Overview`:** Scope, system architecture summary, and QA objectives.
* **`02_End_to_End_Testing_Workflow`:** Visual QA process diagram from requirement analysis to sign-off.
* **`03_Module_Test_Cases`:** Functional, negative, boundary, and edge-case test suites organized by module.
* **`04_Bug_Reports`:** Production and staging defect logs with reproduction steps and severity ratings.
* **`05_Real_World_Scenarios`:** End-to-end business scenarios (including CMDB workflows).
* **`06_Product_Comparison`:** Feature and usability benchmarking across Assets, CMDB, Incident, and Knowledge Base modules.
